# WAVE — Product Requirements Document

> Word And Verse Everyday. 매일 성경 한 장을 읽고 묵상을 기록하는 웹앱.

## Goal

MVP를 빠르게 출시해 시장 반응을 검증한다. 속도와 안정성의 균형을 유지한다.

## Screens

2개만 존재한다. 설정, 프로필 등 부가 화면을 만들지 않는다.

- **홈**: 오늘의 성경 본문 + 묵상 작성
- **기록**: 과거 묵상 목록 (최신순)

하단 탭바로 전환한다.

## Core Flow

회원가입(Google) → 본문 확인 → 묵상 작성 → 기록 조회

## Auth

- Google OAuth 전용. 다른 인증 수단 없음.
- 비로그인 시 모든 기능 차단 → 랜딩 페이지로 리다이렉트.

## Bible Passage

- 유저가 책+장을 직접 선택할 수 있다.
- 선택하지 않으면 자동 할당:
  - 1순위: 오늘 이미 묵상한 기록 → 그 챕터
  - 2순위: 과거 묵상 있음 → 마지막 묵상 +1
  - 3순위: 묵상 없음(신규) → 가입일 기준 경과 일수로 계산
- 통독표: 창세기~계시록 1,189장 순환. 계시록 22장 이후 창세기 1장.
- 수동 선택 후 저장 시 해당 챕터가 마지막 위치로 갱신된다.

## Meditation

- 하루 1개. 같은 날 재작성 시 UPSERT 덮어쓰기.
- 날짜 기준: KST 고정.
- 묵상 내용 10,000자 제한.
- 빈 내용 저장 불가.
- 기록탭에서 과거 묵상 수정 가능. 생성일/수정일 분리 표시.

## Draft

- 타이핑 시 localStorage 자동 저장.
- 저장 내용: `{ book, chapter, content }`.
- 키: `draft_${userId}_${date}`.
- DB 저장 완료 시 삭제. 날짜 변경 시 삭제.
- 복원 시 별도 알림 없음.

## Bible Data

- scripture.api.bible API 사용 (한국어 번역본).
- DB에 챕터 단위 캐싱 → API 의존성 최소화.
- Day 0 작업: API 키 발급 + 한국어 번역 존재 여부 확인 필수.

## Design Constraints

- 포인트 색상 1~3가지 + 무채색만 사용.
- 폰트: Pretendard.
- 그룹 기능, 실시간 기능, 오프라인/PWA 없음.

## Legal

- `/privacy`, `/terms` 정적 페이지 필수 (PIPA, Google OAuth 심사 요건).

## Done Criteria

1. Google 로그인 동작
2. 홈에서 오늘의 성경 본문 표시
3. 책/장 직접 선택 시 해당 본문 표시
4. 묵상 작성 및 저장
5. 기록탭에서 과거 묵상 최신순 표시
6. 재접속 시 마지막 묵상 위치 유지
